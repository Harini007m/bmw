# BMW | Cinematic Luxury Automotive Experience

A premium, high-performance automotive web platform inspired by the engineering excellence of **BMW** and **Porsche**. Built with **React 19**, **Vite**, and **Tailwind CSS v4**.

## 🎯 Core Experience
- **Cinematic Intro**: Elegant font transformation from Serif ("Bayerische Motoren Werke") to Bold Sans-Serif ("BMW") with motion blur.
- **Video-First Hero**: High-impact autoplay video background positioned immediately below a modern glassmorphic navigation bar.
- **Dynamic Model Previews**: interactive showroom where hovering over car cards triggers instant high-fidelity video transitions.
- **Virtual 360 Showroom**: A technical HUD-inspired experience featuring orientation nodes and digital analytics.
- **Premium Aesthetics**: Dark mode design system with metallic accents, glassmorphism, and smooth cubic-bezier easing.

## 🛠 Tech Stack
- **Framework**: [React](https://react.dev/) + [Vite](https://vitejs.dev/) (Lightning fast HMR)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/) (Engineered with CSS-first configuration)
- **Animations**: [Framer Motion](https://www.framer.com/motion/) (Cinematic orchestrations)
- **Icons**: [Lucide React](https://lucide.dev/) (Clean, minimalist iconography)
- **Routing**: [React Router](https://reactrouter.com/)

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation
1. Clone or download the project.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Launch the development server:
   ```bash
   npm run dev
   ```

## 📁 Project Structure
- `src/components/`: Modular UI elements (Intro, Hero, Navbar).
- `src/pages/`: Main application views (Home, Models, Experience).
- `src/lib/`: Utility functions and design helpers.
- `src/index.css`: Tailwind v4 configuration and global design system.

---

*Note: The `@theme` warning in `index.css` is a known IDE limitation for Tailwind v4 and does not affect the performance or functionality of the application.*
